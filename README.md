# Multi-Crop Leaf Disease Detection with Severity Estimation and Treatment Advice

A deep learning project that identifies the disease on a crop leaf from a single photo. It covers **sugarcane and 14 other crops (44 classes)**, estimates how much of the leaf is diseased, and suggests treatment options. The model is small enough (2.6 MB as TFLite) to be deployed on a mobile phone.

## Features
- Disease classification for 44 classes (sugarcane + 14 PlantVillage crops)
- Severity estimation (% of diseased leaf area) using HSV colour segmentation
- Treatment advice (recommended active ingredients and organic measures) based on the disease and its severity
- Low-confidence warning when the prediction is below 60%
- Gradio web app for live demo
- Quantized TFLite model for mobile deployment

## Datasets
Not included in this repository. They are downloaded automatically by the training notebook.
- PlantVillage: `abdallahalidev/plantvillage-dataset` (Kaggle)
- Sugarcane Plant Diseases Dataset: `akilesh253/sugarcane-plant-diseases-dataset` (Kaggle)

Please check the licence of each dataset on its Kaggle page before reusing the data.

## Method
1. Both datasets are merged into one folder structure (`Crop___Disease`).
2. Model: MobileNetV2 (ImageNet weights) with data augmentation, global average pooling, dropout (0.3) and a softmax classifier.
3. Training: Phase 1 trains only the classifier head; Phase 2 fine-tunes the last 40 layers with a learning rate of 1e-5.
4. Severity: the leaf is separated from the background, and the non-green area inside the leaf is counted as diseased (`severity % = diseased area / leaf area x 100`). This is not predicted by the neural network.
5. Export: post-training quantization to TFLite.

## How to run
**Demo (no training needed)**
1. Open `crop_disease_demo_app.ipynb` in Google Colab.
2. Run all cells and upload `crop_disease_model.keras` and `class_names.json` when asked.
3. Upload a leaf photo in the Gradio app.

**Training**
1. Open `crop_disease_detection.ipynb` in Google Colab and select a T4 GPU runtime.
2. Run all cells (training takes about 30-60 minutes).

## Limitations
- The datasets contain mostly lab-style, single-leaf images. Accuracy on real field photos (cluttered background, multiple leaves) is lower, and the app may show a low-confidence warning.
- The sugarcane dataset contains augmented images, so validation accuracy may be higher than real-world accuracy.
- Mosaic and Yellow (sugarcane) and Early Blight (tomato) are the weakest classes; Mosaic is often confused with Healthy.
- Severity estimation is an approximation and works best on a single leaf against a plain background.
- Only the 44 classes in the training data are supported. Other crops will be misclassified.
